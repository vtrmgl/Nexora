# Nexora

Sistema web de marketplace de informática. Peça seus produtos tecnológicos em um só lugar.

## Funcionalidades
- Cadastro e login de usuários
- Catálogo de produtos com preço, nome e foto
- Carrinho para produtos desejados
- Cadastro de lojas
- Painel de favoritos
- Barra de pesquisa
- Pesquisa por filtro
- Dashboard com dados da loja
- Perfil com imagem do usuário

## Tecnologias
- PHP 8.2
- MySQL 8
- HTML, CSS e JavaScript
- XAMPP (ambiente local)

## Como rodar
1. Instale o XAMPP e ligue Apache e MySQL.
2. Copie a pasta `cantinaweb` para `C:\xampp\htdocs`.
3. No phpMyAdmin, importe `database/nexora.sql`.
4. Acesse http://localhost/Nexora
Passos detalhados em `docs/instalacao.md`.
